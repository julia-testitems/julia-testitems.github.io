# Projects Using Test Items

Test items are used across the Julia ecosystem, from small utility packages to large simulation frameworks. The projects below are **examples** of open-source packages and applications that write their tests as `@testitem` blocks. They were found via a GitHub search and are only a sample of what is out there — the list is not comprehensive and will drift out of date over time.
